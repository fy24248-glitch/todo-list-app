# To-Do List App

A simple, no-framework to-do list web app with browser local storage persistence.

## Features
- Add, complete, and delete tasks
- Tasks persist across page reloads (via `localStorage`)
- Filter: All / Active / Completed
- Task counter

## How to run
Just open `index.html` in your browser, or serve it locally:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Why this project
A to-do app is a classic beginner project for practicing DOM manipulation, event handling, and basic state persistence with `localStorage` — core front-end skills.
